
# Asteroids

A classic Asteroids-style arcade game built with Python and Pygame as part of the Boot.dev object-oriented programming curriculum.

## Features

- Player movement and rotation
- Asteroids that spawn from screen edges
- Shooting with a cooldown
- Collision detection
- Large asteroids splitting into smaller asteroids
- Game-over detection
- JSONL event logging

## Requirements

- Python 3.13+
- uv package manager
- Pygame 2.6.1 (installed with project dependencies)

## Installation and Running

Clone the repository:

```bash
git clone https://github.com/rollindeas/asteroids.git
cd asteroids
```

Install dependencies and run the game:

```bash
uv sync
uv run main.py
```

## Controls

| Key | Action |
|-----|--------|
| W | Move forward |
| S | Move backward |
| A | Rotate left |
| D | Rotate right |
| Space | Shoot |
